## About ASD-123

ASD-123 is an educational mobile application designed to support speech and language development for individuals with autism spectrum disorder. The app provides voice-based interactive exercises under the supervision of parents, guardians, or speech-language pathologists.

### Key Features

- Voice-based interactive exercises
- Progress tracking and reporting
- Clinician/SLP monitoring capabilities
- Privacy-focused design (no audio storage)
- COPPA compliant for children's privacy
- UK GDPR compliant

## Privacy Highlights

- **No voice recordings stored** - Audio is processed in real-time and immediately deleted
- **COPPA compliant** - Parental consent required; minimal data collection
- **UK GDPR compliant** - Full data subject rights; ICO oversight
- **Clinician access controls** - Parents authorize and can revoke SLP access
- **International data transfer safeguards** - Standard Contractual Clauses (SCCs)
